# Online Learning Management System

A microservices-based Online Learning Management System built using Java and Spring Boot.

## Technologies Used
- Java
- Spring Boot
- Spring Cloud Netflix Eureka
- OpenFeign
- REST APIs
- MySQL
- Maven

## Microservices
1. Eureka Server
2. Student Service
3. Course Service
4. Instructor Service
5. Enrollment Service
6. Payment Service
7. Assignment Service
8. Result Service

## Purpose
The project is designed to manage online learning activities through independent microservices that communicate using REST APIs and service discovery.
